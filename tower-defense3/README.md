Tower Defense Prototype

Run:
1. Open index.html in a browser (file:// or serve via a simple static server).
2. Click empty space to place towers (cost 50).
3. Click a tower to select it, Upgrade or Sell.

Notes:
- Prototype uses JavaScript + Canvas and WebAudio for placeholder sounds.
- Files: index.html, game_with_audio.js
- Iteration plan: add more enemy types, wave progression, balancing, assets.
